# CelMarket 📱

**Tienda virtual de celulares y tecnología**

## Descripción

CelMarket es un proyecto universitario desarrollado para el curso de Diseño Web de la Universidad Continental. Consiste en una tienda virtual de celulares que permite explorar productos, buscar dispositivos y gestionar un carrito de compras.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Bootstrap 5.3.9 (integración correspondiente al desarrollo C2)
- LocalStorage para persistencia de datos.

## Funcionalidades

- Catálogo dinámico de celulares.
- Búsqueda de productos por nombre.
- Filtrado por categorías.
- Carrito de compras.
- Modificación de cantidades y control de stock.
- Persistencia del carrito mediante LocalStorage.
- Cupones de descuento.
- Cálculo de subtotal, envío, IGV y total.
- Formularios con validación.

## Instalación y ejecución

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar `index.html` mediante un servidor local o la extensión Live Server de Visual Studio Code.
